LiftLog v3 — Migration Edition
==============================
This version attempts to automatically import workout data from the previous LiftLog versions stored in the same browser.

Important:
- Do NOT clear Safari website data before opening this version.
- Replace the files in your existing GitHub Pages repository with these files.
- Open the same GitHub Pages address on the iPhone/browser where your old data was entered.
- The migration only reads the old local data and copies it into the new v3 storage key; it does not intentionally delete the old key.
- Weight/load is free-form text.
- Numeric weight +/- buttons change by 2.5.
- Reps +/- buttons change by 1.
- Delete This Workout removes the entire workout column.
